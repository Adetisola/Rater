# Rater — Personality & Brand Voice Application Map

This document maps where Rater’s personality should be applied across the product while preserving clarity, usability, and premium UX.

Core Direction:

* Calm
* Creative
* Premium
* Minimal
* Human
* Slightly witty
* Subtly Nigerian
* Never loud
* Never meme-heavy
* Never confusing

Rule:
Functional language stays standard.
Atmospheric language gets personality.

---

# 1. SEARCH BAR PLACEHOLDERS

## Current

* Search title, avatar, or category
* Good morning
* Welcome back

## Replace With

### Functional

* Search work, creatives, or categories
* Search logos, interfaces, posters...
* Find something sharp.
* Looking for inspiration?
* Search titles, avatars, or tags

### Ambient / Personality

* What are you exploring today?
* Still designing?
* Omo, late session?
* Ideas no dey sleep.
* Another midnight push?
* Creative juices still flowing?
* Burning pixels tonight?
* Welcome back.
* Something clean today?
* Let’s see what people are cooking.

IMPORTANT:

* Rotate subtly
* Never too frequent
* Keep transitions smooth
* Avoid emojis

# 22. AREAS THAT SHOULD REMAIN STANDARD

DO NOT stylize:

* Sign in
* Create account
* Username
* Password
* Search
* Submit
* Post
* Report
* Settings
* Privacy
* Security
* Delete permanently
* Email
* Upload image
* Accessibility labels
* Form validation
* Moderation language
* Legal pages

These should remain universally understandable.

---

# FINAL BRAND VOICE RULES

Rater should feel like:

* a calm creative environment
* a product built by designers
* internationally usable
* subtly Nigerian underneath

The personality should appear in:

* moments of waiting
* discovery
* transitions
* onboarding
* ambient interaction
* emotional microcopy

NOT in:

* critical UX
* destructive actions
* navigation clarity
* security flows
* accessibility-critical language

The goal is:
"designed by people with taste."
